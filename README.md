# Blinkit-Grocery-Data-Analysis

# 🛒 Blinkit Grocery Data Analysis (Excel Project)

## 📌 Overview
This project analyzes Blinkit grocery sales data using Microsoft Excel.  
The focus is on extracting meaningful business insights through data cleaning, pivot tables, and visualization.

---

## 🎯 Objectives
- Analyze overall sales performance  
- Identify top-selling products and categories  
- Evaluate outlet performance  
- Understand customer buying patterns  

---

## 📂 File Included
- BlinkIT Grocery Excel Project File.xlsx  

---

## 🛠️ Tools Used
- Microsoft Excel  
  - Data Cleaning  
  - Pivot Tables  
  - Charts & Visualization  

---

## 🗃️ Dataset Description
The dataset includes:
- Product details (Item Type, Fat Content)  
- Sales data (Total Sales, Quantity)  
- Outlet information (Location, Size, Type)  

---

## 🔍 Key Analysis

### 📊 Sales Analysis
- Total sales and average sales  
- Sales by product category  
- Category-wise performance  

### 🏪 Outlet Analysis
- Sales by outlet size  
- Sales by outlet location  
- Performance comparison of outlet types  

### 🛍️ Product Insights
- Top-selling products  
- Category demand analysis  
- Impact of fat content on sales  

---

## 📈 Excel Features Used
- Pivot Tables  
- Pivot Charts  
- Sorting & Filtering  
- Data Cleaning Techniques  

---

## 📊 Key Insights
- Identified high-performing product categories  
- Found best-performing outlet types  
- Observed sales differences based on location  
- Understood customer product preferences  

---
